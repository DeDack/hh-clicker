# HH Clicker Clean

Локальный помощник для откликов на hh.ru.

Работает только с тем URL поиска, который вы сами вставили в интерфейс.

## Как запустить

Нужен Docker.

```bash
cd hh-clicker-clean
docker compose up -d --build
```

Открыть в браузере:

```text
http://127.0.0.1:8001
```

Остановить:

```bash
docker compose stop
```

## Как пользоваться

1. Откройте hh.ru в браузере и войдите в аккаунт.
2. На любой странице hh.ru откройте DevTools -> Network.
3. Найдите запрос к `hh.ru`, нажмите правой кнопкой -> Copy -> Copy as cURL.
4. Вставьте cURL в блок `Сессия HH` и нажмите `Импортировать`.
5. При необходимости нажмите `Проверить cookies`, чтобы убедиться, что сессия HH еще жива.
6. Выберите резюме.
7. Введите сопроводительное письмо.
8. Вставьте URL поиска вакансий HH.
9. Укажите количество страниц.
10. Нажмите `Проверить поиск`.
11. Удалите из preview вакансии, на которые не хотите откликаться.
12. Нажмите `Запустить отклики`.

## Важно

- Отклики отправляются только по вакансиям из preview snapshot.
- Если вакансии не было в preview, приложение на неё не откликнется.
- Дубли HH удаляются по `vacancy_id`.
- Вакансии с тестами пропускаются.
- Кнопка `Остановить` завершает работу перед следующим запросом.
- Кнопка `Сбросить данные` удаляет локальные cookies, письмо, URL и историю откликов.

## Личные данные

Cookies, резюме, письмо и история откликов хранятся не в проекте, а рядом:

```text
../hh-clicker-clean-userdata
```

Эту папку никому не отправляйте.

Чтобы передать проект другу, передавайте только папку:

```text
hh-clicker-clean
```

Без папки:

```text
hh-clicker-clean-userdata
```
