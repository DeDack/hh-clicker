# HH Clicker Clean

Локальный помощник для откликов на hh.ru.

Работает только с тем URL поиска, который вы сами вставили в интерфейс.

## Как запустить

Нужен Docker.

Для персональных писем нужен LLM-ключ. Скопируйте пример env и заполните только локально:

```bash
cp .env .env
```

В `.env` задайте:

```text
LLM_PROVIDER=komapi
KOMAPI_API_KEY=ваш_ключ
KOMAPI_BASE_URL=https://www.komapi.top
KOMAPI_MODEL=claude-haiku-4-5
```

```bash
cd hh-clicker-clean
docker compose up -d --build
```

Открыть в браузере:

```text
http://127.0.0.1:8001
```

Остановить:

```bash
docker compose stop
```

## Как пользоваться

1. Откройте hh.ru в браузере и войдите в аккаунт.
2. На странице со своим резюме hh.ru откройте DevTools -> Network.
3. Перезагрузите страницу и найдите первый запрос к `hh.ru`, нажмите правой кнопкой -> Copy -> Copy as cURL.
4. Вставьте cURL в блок `Сессия HH` и нажмите `Импортировать`.
5. При необходимости нажмите `Проверить cookies`, чтобы убедиться, что сессия HH еще жива.
6. Выберите резюме.
7. Для персональных писем нажмите `Сохранить текст резюме локально`, чтобы приложение сохранило очищенный текст резюме в userdata и не загружало его с HH для каждой вакансии.
8. Введите сопроводительное письмо для общего режима.
9. Вставьте URL поиска вакансий HH.
10. Укажите количество страниц.
11. Нажмите `Проверить поиск`.
12. Удалите из preview вакансии, на которые не хотите откликаться.
13. Нажмите `Запустить отклики`.

Для теста одного отклика откройте:

```text
http://127.0.0.1:8001/single
```

На этой странице можно вставить URL одной вакансии, написать письмо вручную или сгенерировать его и отправить один реальный отклик.

## LLM и KomAPI

Персональные сопроводительные письма по умолчанию генерируются через KomAPI:

```text
POST https://www.komapi.top/v1/messages
```

Модель по умолчанию:

```text
claude-haiku-4-5
```

Для генерации используется Anthropic Messages API. Важно: `/v1/messages` вызывается с заголовками:

```http
x-api-key: $KOMAPI_API_KEY
anthropic-version: 2023-06-01
content-type: application/json
```

Диагностический `/v1/models` у KomAPI проверяется отдельно и использует:

```http
Authorization: Bearer $KOMAPI_API_KEY
```

Проверить подключение можно кнопкой `Проверить подключение` в блоке письма или запросом:

```bash
curl http://127.0.0.1:8001/api/llm/status
```

Персональный режим требует настроенный LLM-ключ. Режим `Одно письмо для всех вакансий` работает без LLM и использует текст, введённый пользователем.

Текст выбранного резюме для prompt сохраняется локально в userdata:

```text
../hh-clicker-clean-userdata/resumes/
```

Массовая генерация читает этот текст один раз из локального кэша и держит его в памяти во время обработки snapshot. Если кэша ещё нет, резюме загрузится с HH один раз и будет сохранено.

Переключение на OpenAI-compatible провайдера:

```text
LLM_PROVIDER=openai
LLM_API_KEY=ваш_ключ
LLM_API_URL=https://api.openai.com/v1/chat/completions
LLM_MODEL=gpt-4o-mini
```

Ключ не возвращается во frontend и не должен попадать в git. Не вставляйте настоящий ключ в README, HTML, JavaScript или docker-compose.

Ручная проверка моделей KomAPI:

```bash
curl "https://www.komapi.top/v1/models" \
  -H "Authorization: Bearer $KOMAPI_API_KEY"
```

Ручная проверка генерации KomAPI:

```bash
curl -X POST "https://www.komapi.top/v1/messages" \
  -H "x-api-key: $KOMAPI_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  --data-raw '{
    "model": "claude-haiku-4-5",
    "max_tokens": 500,
    "messages": [
      {
        "role": "user",
        "content": "Напиши одно короткое предложение на русском языке."
      }
    ]
  }'
```

## Важно

- Отклики отправляются только по вакансиям из preview snapshot.
- Если вакансии не было в preview, приложение на неё не откликнется.
- Дубли HH удаляются по `vacancy_id`.
- Вакансии с тестами пропускаются.
- Кнопка `Остановить` завершает работу перед следующим запросом.
- Кнопка `Сбросить данные` удаляет локальные cookies, письмо, URL и историю откликов.

## Личные данные

Cookies, резюме, письмо и история откликов хранятся не в проекте, а рядом:

```text
../hh-clicker-clean-userdata
```

Эту папку никому не отправляйте.

Чтобы передать проект другу, передавайте только папку:

```text
hh-clicker-clean
```

Без папки:

```text
hh-clicker-clean-userdata
```
